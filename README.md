## 1. First C Program

A C program starts execution from the main() function.

### Key Components
- #include <stdio.h> : Standard input/output header file
- main() : Entry point of the program
- printf() : Used to display output
- return 0 : Indicates successful execution

Example:
```c
#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}
